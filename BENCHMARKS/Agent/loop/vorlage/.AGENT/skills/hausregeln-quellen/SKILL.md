# Hausregeln für Quellenangaben

## Wann

Bei jedem Bericht, der sich auf Unterlagen stützt, besonders bei
Berichten an die Betriebsleitung.

## Regeln

1. **Jede Aussage aus einer Unterlage** bekommt direkt dahinter eine
   Angabe in genau dieser Form: `[Q: dateiname.md, Abschnitt N]`.
   N ist die Nummer der Überschrift `## N.` in der Datei.
2. **Zahlen aus einer eigenen Auswertung** bekommen
   `[Q: ergebnis/statistik.md]`.
3. **Eine ersetzte Unterlage ist kein Beleg.** Steht in ihrem Kopf
   `Ersetzt durch:`, gilt die neuere. Die ältere darf erwähnt werden,
   aber nur als veraltet.
4. **Am Ende** steht ein Abschnitt `## Quellen` mit einer Zeile je
   verwendeter Unterlage: Dateiname und ihr `Stand:`-Datum.

## Beispiel

Der Kühlraum darf höchstens 8,0 °C haben [Q: grenzwerte-2026.md, Abschnitt 2].

## Quellen

- grenzwerte-2026.md, Stand 2026-02-02
