# Maßnahmen bei Abweichungen im Serverraum

Stand: 2026-02-02

## 1. Sofort

Liegt ein Messwert über dem zulässigen Bereich, wird die Last auf
nicht dringende Dienste reduziert und ein Wartungsauftrag für die
Klimaanlage angelegt.

## 2. Keine Maßnahme

Werte innerhalb des zulässigen Bereichs erfordern keine Maßnahme, auch
wenn sie über früheren Grenzen liegen.
