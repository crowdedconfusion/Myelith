# networking (`myl-net`)

> **Version:** 0.0.0
> **Datum:** 2026-08-10
> **Status:** Phase 0 – nicht begonnen

P2P-Gossip, latenzbasierte Topologie-Erkennung, verschlüsselte Aktivierungs-Streams. Referenzimplementierung von Whitepaper Kap. 3.2 (L0 Networking Layer), Grundlage für die Latenzmessung aus Kap. 4.1/4.3.

## Ziel

Die unterste Schicht (L0): Peer-Discovery, Gossip-Verbreitung von Blöcken/Transaktionen/Attestierungen, kontinuierliche Paarlatenzmessung für die Pod-Bildung, und Ende-zu-Ende-verschlüsselte Punkt-zu-Punkt-Kanäle für Aktivierungs-Streams zwischen Shard-Minern (Kap. 9.2). Abhängigkeit: nur SHARED_TYPES (Nachrichtenformate). Kann parallel zu INTEGER_LLM und SHARED_TYPES begonnen werden.
