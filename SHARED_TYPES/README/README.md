# shared-types (`myl-types`)

> **Version:** 0.0.0
> **Datum:** 2026-08-10
> **Status:** Phase 0 – nicht begonnen

Protokollweite Kern-Datentypen, Hash-/Merkle-Primitiven und Serialisierung für Myelith. Referenzimplementierung von Whitepaper Anhang A.1 (`myl-types`).

## Ziel

Ein einziges Crate, von dem alle anderen Komponenten (NETWORKING, CONSENSUS, VERIFICATION, TOKENOMICS, COMPUTE_PIPELINE, AGENT_LAYER, TRAINING) dieselben Basistypen beziehen, damit `Segment`, `PoIBundle`, Hashes und Signaturen niemals in zwei Komponenten inkompatibel definiert werden. Diese Komponente hat keine Abhängigkeit zu anderen Myelith-Komponenten und kann sofort begonnen werden.
