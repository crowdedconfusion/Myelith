# Die Kalibrier-Umgebung mit festen Fassungen (Python 3.12), seit dem
# 2026-10-21 eine fuer alle Bauarten.
#
# Warum fest: Der Gitterbau der Experten in vier Bit rechnet in torch.
# Eine andere Fassung kann eine Summe anders ordnen, eine Rundung kippen
# und damit andere Gewichte ergeben. Mit diesen Fassungen baut derselbe
# Rechner bitgleich; `requirements.txt` nennt nur die Untergrenzen.
#
# ⚑ Bis zum 2026-10-21 gab es zwei Umgebungen: diese mit transformers 5.15.0
#   fuer alle Bauten und eine zweite mit 5.18.0 nur fuer die Bauart mit vier
#   Stroemen (`qwen4_exp` gibt es erst ab 5.18.0). Zusammengelegt auf den Satz
#   der zweiten, nach drei Gegenproben mit 5.18.0: das 0,6B aus dem
#   Skalenpaket bitgleich (636 von 636 Dateien, Manifest wie im Register);
#   das Laden von Qwen3-Gemisch, Qwen3.5 dicht und Qwen3.5-Gemisch (Experten
#   einzeln und verschmolzen) Tensor fuer Tensor bitgleich; WikiText mit der
#   geprueften Summe. torch ist in beiden Saetzen dieselbe Fassung. Anders als
#   vorher: transformers, datasets, huggingface-hub (2.x), tokenizers und die
#   HTTP-Bibliothek des Hub (httpx2 statt httpx).
#
# ⚑ Seit dem 2026-10-23 mit pillow, fuer die Gleitkomma-Referenz des

#   Vorlage braucht es, torchvision dagegen nicht. 13.0.0 ist die erste Fassung
#   ohne bekannte Meldung.
